# Balsas Experience API

API REST desenvolvida na disciplina de **Programação para Web** para disponibilizar informações sobre atrações turísticas do município de Balsas-MA.

O projeto foi desenvolvido utilizando Node.js e Express para construção da API, PostgreSQL para armazenamento dos dados e Prisma ORM para integração entre a aplicação e o banco de dados.
